# GojeID - PHP SDK untuk Gojek API

## 📋 Instalasi

### 1. Clone atau buat project baru
mkdir gojeki-project
cd gojeki-project

### 2. Install via Composer
composer require maulana20/gojekid
composer require guzzlehttp/guzzle --ignore-platform-req=php

### 3. Fix Namespace Issue
Edit vendor/maulana20/gojekid/src/HTTP/Curl.php
